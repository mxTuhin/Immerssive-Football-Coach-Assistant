# Metrica sample data (bundled)

From https://github.com/metrica-sports/sample-data (see `METRICA_README.md`; acknowledge the source when used
publicly). Large files are gzipped. Games 1–2: `fmi_schema.adapters.metrica.load_match(root, game)`.
Game 3 (EPTS format): `fmi_schema.adapters.kloppy_adapter.load_metrica_epts(root)` (needs `pip install kloppy`).
